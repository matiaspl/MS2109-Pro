# MS2109-Pro experiments archive

Browse the [GitHub Pages documentation site](https://matiaspl.github.io/MS2109-Pro/) for interactive HTML reports and rendered Markdown. The complete research history and development workspace are under [`development/`](development/README.md). Its inventory maps the original paths to their archived locations and records each original file's SHA-256.

This branch preserves experiment code, firmware candidates, captures, backups and reports. The release branch is `master`.

A 4.7 GB local-only repair capture set has also been moved under `development/artifacts/ms2109-repair-local-only/`. Its files are excluded from GitHub because of their size and raw formats; `development/FILE_INVENTORY.tsv` records their paths and SHA-256 hashes. The files remain in this local experiments worktree.

The same numeric address in different spaces is a different location. For example, CODE 0040 is not XDATA 0040. Use the address-space label whenever citing an address.
Evidence and confidence labels

Verified path: instruction-level reads, writes, data flow, or image layout were traced in the pinned firmware. This proves software behavior, not necessarily electrical meaning.

Observed: a live measurement or protocol result is linked from a prior report. Conditions are specific to those tests.

Inferred / unresolved: a likely role or candidate exists, but exact silicon fields, reset behavior, or side effects are not established. Sparse XDATA entries do not make every address in a family a register.
